# CTC-GTS v2 — ระบบติดตามภาวะการมีงานทำ (ทุกสาขาวิชา)
Deploy: แตก zip → vercel.com → Add New → Project → Deploy without Git → ลากโฟลเดอร์ไปวาง (Vite ตรวจพบอัตโนมัติ)
หรือในเครื่อง: npm install && npm run dev  /  npm run build (ได้โฟลเดอร์ dist/ อัปโหลดขึ้น hosting ใดก็ได้)
หมายเหตุ: ตอนนี้เป็นข้อมูลจำลอง และสิทธิ์ผู้ใช้เป็นโหมดสาธิตฝั่งหน้าเว็บ ใช้งานจริงต้องมีระบบล็อกอิน/ฐานข้อมูลฝั่งเซิร์ฟเวอร์


## รูปนักศึกษาประจำสาขา
วางรูปจริง (ที่ได้รับความยินยอมแล้ว) ไว้ที่ public/students/ แล้วระบุใน PHOTO_URLS ของ src/App.jsx หรือกดอัปโหลดรูปในระบบ (ชั่วคราว หายเมื่อรีเฟรช)
